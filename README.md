# oi-booth

A modern photo booth built on [pibooth](https://github.com/pibooth/pibooth) for Raspberry Pi. Adds a phone-accessible web admin panel, guest gallery with QR retrieval, GIF/Boomerang modes, AI background removal, drag-and-drop template editor, event management, email sharing, printer controls, attract slideshow, LED lighting control, and OTA updates — all without requiring a touchscreen or external cloud service.

## Features

| Feature | Description |
|---|---|
| **Web Admin** | Phone-friendly operator panel on local WiFi — no touchscreen needed |
| **PIN Auth** | 4-digit PIN locks all admin routes; gallery stays public |
| **CoPilot** | Trigger captures, switch modes, live status dot, LED controls from your phone |
| **Template Editor** | Drag-and-drop canvas editor for photo layouts — backgrounds, overlays, footer text |
| **Gallery** | Guest-facing photo gallery with QR code on finish screen |
| **Email Sharing** | Guests email their photo directly from the gallery page (SMTP, no third-party) |
| **Print from Gallery** | One-tap print button on the guest session page (CUPS) |
| **GIF + Boomerang** | Animated GIF and boomerang capture modes |
| **AI Background Removal** | Replace backgrounds using rembg — gated to Pi 4+ at runtime |
| **Events** | Create named events; photos are organized into per-event galleries |
| **Printer Status** | CUPS printer discovery, job queue, test print, job cancel |
| **Health Monitor** | Storage, camera, printer, and booth status with OTA update button |
| **Attract Slideshow** | Upload images that cycle on the idle screen between sessions |
| **Lighting Controls** | Turn capture/print LEDs on, off, or blinking from CoPilot |
| **USB Storage** | Auto-detects USB drives; one-click to redirect photo storage |
| **PWA** | Gallery is installable on iOS/Android as a home screen app |

## Hardware

- Raspberry Pi 3B+ or 4 (Pi 4 required for AI background removal)
- Raspberry Pi Camera Module (any version)
- HDMI display/TV
- 2× push buttons (GPIO)
- 2× LEDs (optional, GPIO)
- USB printer (optional, CUPS)
- USB drive (optional, for photo storage)

## Quick Install

```bash
# On the Pi, as the pi user:
git clone https://github.com/hlbiv/oi-booth.git ~/oi-booth
bash ~/oi-booth/scripts/install.sh
```

The installer will:
- Install system dependencies (Python, SDL2, CUPS, fonts)
- Create a virtualenv and install Python packages
- Copy the plugin and support modules to `~/.config/pibooth/plugins/`
- Scaffold `~/.config/pibooth/pibooth.cfg` with the plugin path pre-set
- Create required directories (backgrounds, overlays, attract, events)
- Generate a `.env` file with a random secret key
- Register and start `oi-web.service` (web admin) and `oi-booth.service` (pibooth)

After install, open a browser on your phone (same WiFi):

```
http://<pi-ip>:5000/admin
```

Default PIN: **1234** — change it in `.env` → `OI_ADMIN_PIN`.

## Configuration

All runtime settings live in `~/oi-booth/.env`:

```env
OI_ADMIN_PIN=1234           # Change this
OI_SECRET_KEY=<generated>   # Auto-generated by installer
OI_STORAGE_DIR=/media/usb/oi-booth-photos

# Email sharing (optional)
OI_MAIL_SERVER=smtp.gmail.com
OI_MAIL_PORT=587
OI_MAIL_USERNAME=you@gmail.com
OI_MAIL_PASSWORD=your-app-password
OI_MAIL_FROM=oi-booth <you@gmail.com>
```

Booth hardware settings (GPIO pins, capture count, orientation, etc.) are in `~/.config/pibooth/pibooth.cfg` and can also be edited via the web admin Config tab.

## Services

```bash
# Start / stop
sudo systemctl start oi-booth oi-web
sudo systemctl stop  oi-booth oi-web

# Live logs
journalctl -u oi-booth -f
journalctl -u oi-web -f

# OTA update (also available as a button in Admin → Health)
cd ~/oi-booth && git pull && pip install -r requirements.txt
sudo systemctl restart oi-booth oi-web
```

## Web Admin Routes

| URL | Access | Description |
|---|---|---|
| `/admin` | PIN | Main dashboard — config, assets, storage, maintenance |
| `/admin/copilot` | PIN | Live operator remote control |
| `/admin/templates` | PIN | Drag-and-drop template editor |
| `/admin/events/` | PIN | Create and manage events |
| `/admin/printer` | PIN | Printer status, test print, job queue |
| `/admin/ops` | PIN | Health monitor, OTA update button |
| `/admin/display` | PIN | Upload attract slideshow images |
| `/admin/lighting` | PIN | LED on/off/blink controls |
| `/gallery` | Public | Guest photo gallery |
| `/gallery/<session_id>` | Public | Individual session — download, email, print |
| `/gallery/event/<id>` | Public | Per-event guest gallery |

## Capture Modes

Set via CoPilot or `[OIBOOTH] mode` in pibooth.cfg:

| Mode | Description |
|---|---|
| `photo` | Standard still photo (default) |
| `gif` | Animated GIF from multiple frames |
| `boomerang` | GIF that plays forward then reverses |

## Guest Flow

1. Guests approach the booth and see the attract slideshow
2. Press the physical button → countdown → captures
3. Finish screen shows a QR code and URL
4. Guest scans QR with their phone
5. Photo opens in their browser — download, share, email, or print

## Development

```bash
git clone https://github.com/hlbiv/oi-booth.git
cd oi-booth
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # edit as needed
python -m web.app      # starts on http://localhost:5000
```

The pibooth plugin (`booth/plugin.py`) requires a running pibooth process and a display. For web-only development, the Flask app works standalone — IPC reads gracefully return empty state when pibooth is not running.

```

│   ├── attract.py      # Attract slideshow helpers
│   └── events.py       # Event management (create, start, stop)
├── web/
│   ├── app.py          # Flask application factory + blueprint registration
│   └── routes/
│       ├── admin.py    # Config, assets, storage, logs
│       ├── auth.py     # PIN login/logout
│       ├── copilot.py  # Remote operator control
│       ├── events.py   # Event admin + guest gallery
│       ├── gallery.py  # Public photo gallery
│       ├── lighting.py # LED controls
│       ├── ops.py      # Health check + OTA update
│       ├── printer.py  # CUPS printer management
│       ├── sharing.py  # Email photo delivery
│       ├── templates_editor.py  # Template CRUD
│       └── display_settings.py # Attract image upload
├── config/
│   ├── pibooth.cfg     # Default pibooth configuration
│   └── templates/      # Saved layout templates (JSON)
├── scripts/
│   ├── install.sh      # One-shot Pi installer

├── services/
│   ├── oi-booth.service  # systemd unit for pibooth
│   └── oi-web.service    # systemd unit for Flask web server
└── requirements.txt
```
